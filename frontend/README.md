# Workspace Allocation System - Frontend

This is the React frontend for the Workspace Allocation System.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The app will be available at http://localhost:3000

## Backend Dependency

Make sure the Spring Boot backend is running on http://localhost:8080 before starting the frontend.

## Features

- Interactive seat grid with drag-and-drop assignment
- Employee management with CRUD operations
- Real-time dashboard with statistics
- Responsive design for all devices
- Toast notifications for user feedback

## Technologies

- React 18
- Tailwind CSS
- Axios for API calls
- React Hot Toast for notifications
- Lucide React for icons
